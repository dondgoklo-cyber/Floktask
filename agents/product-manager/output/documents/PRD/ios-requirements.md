## 🎯 Исполнительное резюме

iOS версия Floktask — это портирование существующего Android приложения на платформу iOS с сохранением всего функционала и адаптацией под специфику платформы. Цель: предоставить пользователям iOS те же возможности, что и пользователи Android, с учетом особенностей iOS экосистемы.

**Ключевые цели:**
- Полное покрытие функциональности Android версии
- Адаптация под iOS дизайн-гайдлайны (Human Interface Guidelines)
- Интеграция с iOS специфичными функциями (Siri, Widgets, iCloud)
- Бесшовная синхронизация между Android и iOS

## 🎯 Требования

### Функциональные требования (Functional Requirements)

#### 🔴 Приоритет P0: Базовый функционал (MVP)

**[FR-001]** Аутентификация и авторизация  
- **Описание:** Реализация системы входа/регистрации
- **Требование:** Поддержка email/пароль, Google Sign-In, Apple Sign-In
- **Приоритет:** Critical
- **Сложность:** Medium

**[FR-002]** Основные сущности  
- **Описание:** Реализация всех основных сущностей Floktask
- **Требование:** Задачи, проекты, теги, заметки, финансы, привычки, энергия
- **Приоритет:** Critical
- **Сложность:** High

**[FR-003]** Основные представления  
- **Описание:** Реализация основных экранов
- **Требование:** Inbox, Upcoming, Projects, Finance, Notes, Habits, Today
- **Приоритет:** Critical
- **Сложность:** High

**[FR-004]** Создание/редактирование задач  
- **Описание:** Полный функционал работы с задачами
- **Требование:** Создание, редактирование, удаление, архивация
- **Приоритет:** Critical
- **Сложность:** Medium

**[FR-005]** Локальное хранение  
- **Описание:** Хранение данных в локальной базе
- **Требование:** Core Data или Realm
- **Приоритет:** Critical
- **Сложность:** Medium

**[FR-006]** Синхронизация с сервером  
- **Описание:** Синхронизация с существующим бэкендом
- **Требование:** Использование существующих API
- **Приоритет:** Critical
- **Сложность:** High

#### 🟡 Приоритет P1: Расширенный функционал

**[FR-007]** iOS специфичные функции  
- **Описание:** Интеграция с iOS экосистемой
- **Требование:** Siri Shortcuts, Widgets, iCloud Sync (опционально)
- **Приоритет:** High
- **Сложность:** Medium

**[FR-008]** Voice Input  
- **Описание:** Голосовой ввод задач
- **Требование:** Интеграция с Speech Framework
- **Приоритет:** High
- **Сложность:** Medium

**[FR-009]** Уведомления  
- **Описание:** Локальные и push уведомления
- **Требование:** UNUserNotificationCenter, APNs
- **Приоритет:** High
- **Сложность:** Medium

**[FR-010]** Поиск  
- **Описание:** Глобальный поиск по всем сущностям
- **Требование:** Поиск по задачам, проектам, заметкам, финансам
- **Приоритет:** Medium
- **Сложность:** Medium

#### 🟢 Приоритет P2: Дополнительные функции

**[FR-011]** Dark Mode  
- **Описание:** Поддержка темной темы
- **Требование:** Автоматическое и ручное переключение
- **Приоритет:** Medium
- **Сложность:** Low

**[FR-012]** Face ID / Touch ID

- **Приоритет:** Medium
- **Сложность:** Low

**[FR-013]** Haptic Feedback

- **Сложность:** Low

**[FR-014]** Adaptive Layout  
- **Описание:** Адаптация под разные размеры экранов
- **Требование:** Поддержка iPhone и iPad
- **Приоритет:** Medium
- **Сложность:** Medium

**[NFR-003]** Поддержка версий iOS  
- **Описание:** iOS 15+
- **Приоритет:** High

**[NFR-004]** Поддержка устройств  
- **Описание:** iPhone (все модели), iPad (все модели)
- **Приоритет:** High

**[NFR-005]** Доступность  
- **Описание:** Поддержка VoiceOver, Dynamic Type
- **Приоритет:** Medium

## 🏗️ Техническая архитектура

### Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Язык** | Swift 5.9+ | Основной язык разработки |
| **UI Framework** | SwiftUI | Основной фреймворк для UI |
| **Архитектура** | MVVM + Clean Architecture | Архитектурный паттерн |
| **Хранение данных** | Core Data | Локальная база данных |
| **Сеть** | URLSession + Combine | Сетевые запросы |
| **DI** | Manual DI | Dependency Injection |
| **Навигация** | Custom Navigation | Навигация между экранами |
| **Логгирование** | OSLog | Системное логгирование |
