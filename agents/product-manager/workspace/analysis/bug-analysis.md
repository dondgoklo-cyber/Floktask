## 📋 Исполнительное резюме

В ходе анализа кода Floktask было выявлено **8 файлов**, в которых присутствуют проблемы с обработкой переносов строк. Основные проблемы связаны с:

1. **Несоответствием форматов переносов строк** (LF vs CRLF) в коде
2. **Неправильной обработкой переносов строк** в пользовательском контенте (заметках, транзакциях)
3. **Отсутствием унифицированного подхода** к обработке мультилайн контента

## 📊 Детальный анализ

### Проблема 1: Потеря форматирования при экспорте

**Файлы:** `NoteExportManager.kt`, `FinanceExportManager.kt`

**Код:**
```kotlin
// NoteExportManager.kt:79
val note = tx.note?.replace(",", ";")?.replace("\n", " ") ?: ""

// FinanceExportManager.kt:45  
val note = tx.note?.replace(",", ";")?.replace("\n", " ") ?: ""
```

**Проблема:**
- Переносы строк в заметках и описаниях транзакций заменяются на пробелы
- Это приводит к потере структуры данных при экспорте в CSV
- Пользователь теряет информацию о разбиении на абзацы

**Решение:**
- Использовать экранирование переносов строк для CSV формата
- Для Markdown сохранять переносы строк как есть
- Добавить опцию для пользователя выбирать формат обработки

### Проблема 2: Несоответствие форматов в NoteEditScreen

**Файл:** `NoteEditScreen.kt`

**Код:**
```kotlin
ToolbarButton(Icons.Filled.Code, "Код") { onInsert("```\n", "\n```") }
```

**Проблема:**
- При вставке кода используются только LF (`\n`)
- На Windows системах это может вызывать проблемы отображения
- Нет обработки CRLF последовательностей

**Решение:**
- Использовать `System.lineSeparator()` для кроссплатформенности
- Добавить обработку CRLF при вставке и редактировании

### Проблема 3: Импорт Markdown

**Файл:** `NoteExportManager.kt`

**Код:**
```kotlin
val content = lines.drop(contentStart).joinToString("\n")
```

**Проблема:**
- При импорте Markdown файлов переносы строк нормализуются к LF
- Это может приводить к потере информации о форматировании
- Нет обработки CRLF последовательностей

**Решение:**
- Сохранять оригинальное форматирование
- Добавить опцию нормализации переносов строк
