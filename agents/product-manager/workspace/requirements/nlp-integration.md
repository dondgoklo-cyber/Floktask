# 🔗 Интеграция RussianVoiceParser с UI

**ID Задачи:** PM-002  
**Статус:** 🟡 In Progress  
**Дата:** 2026-09-05  
**Автор:** Product Manager Agent

---

## 📋 Исполнительное резюме

Задача заключается в полной интеграции существующего парсера RussianVoiceParser с пользовательским интерфейсом Floktask. В настоящее время парсер успешно используется в VoiceTaskSheet, но требуется улучшение пользовательского опыта, расширение функциональности и обеспечение кроссплатформенности.

---

## 🎯 Текущее состояние

### ✅ Уже реализовано:

1. **RussianVoiceParser** (`app/src/main/java/com/taskmanager/voice/RussianVoiceParser.kt`)
   - Rule-based парсер для русского языка
   - Поддержка:
     - Даты: "сегодня", "завтра", "вчера", "через N дней", "N августа", "DD.MM.YYYY"
     - Время: "в 15:00", "в 3 часа утра", "в 8 вечера", "полдень", "полночь"
     - Приоритеты: "срочно", "высокий", "средний", "низкий"
     - Проекты: "в проект X"
     - Теги: "тег работа", "теги дом, покупки"
     - Повторяемость: "каждый день", "еженедельно", "ежемесячно", "ежегодно"
     - Финансы: "расход 1500 на продукты", "доход 120000 зарплата"

2. **TaskDraft** (`app/src/main/java/com/taskmanager/voice/TaskDraft.kt`)
   - Модель данных для результата парсинга
   - Поддержка всех параметров задачи

3. **VoiceTaskSheet** (`app/src/main/java/com/taskmanager/presentation/screens/voice/VoiceTaskSheet.kt`)
   - Modal Bottom Sheet с распознаванием речи
   - Предпросмотр распознанной задачи
   - Редактирование заголовка
   - Отображение извлеченных данных (дата, время, приоритет, теги, повторяемость)

4. **CreateMenuSheet** (`app/src/main/java/com/taskmanager/presentation/components/CreateMenuSheet.kt`)
   - Кнопка "Задача голосом" с иконкой микрофона
   - Интеграция с VoiceTaskSheet

## 🎯 Требования к интеграции

### Функциональные требования (Functional Requirements)

#### FR-001: Расширенный парсинг дат и времени
- **Описание:** Расширить поддержку форматов дат и времени
- **Текущее состояние:** Базовая поддержка
- **Требование:** Поддержка "в следующей неделе", "в следующем месяце", "через 2 недели", "на выходных"
- **Приоритет:** High
- **Сложность:** Medium

#### FR-002: Поддержка контекста задачи
- **Описание:** Извлекать дополнительный контекст из речи
- **Требование:**
  - Описание задачи (длинный текст)
  - Категория/проект (улучшенный парсинг)
  - Подзадачи ("и еще...")
  - Вложения/напоминания
- **Приоритет:** Medium
- **Сложность:** High

#### FR-003: Улучшенный UI VoiceTaskSheet
- **Описание:** Улучшить пользовательский интерфейс
- **Требование:**
  - Анимация распознавания речи
  - Визуальная обратная связь при парсинге
  - Подтверждение перед созданием
  - История голосовых команд
- **Приоритет:** High
- **Сложность:** Medium

#### FR-004: Кроссплатформенность
- **Описание:** Обеспечить работу на всех платформах
- **Требование:**
  - iOS поддержка (Swift)
  - Web поддержка (Web Speech API)
  - Desktop поддержка
- **Приоритет:** Medium
- **Сложность:** High

#### FR-005: Интеграция с другими модулями
- **Описание:** Интеграция с финансами, заметками, проектами
- **Требование:**
  - Создание задач из голоса в любом модуле
  - Контекстно-зависимый парсинг
  - Быстрое добавление через голос
- **Приоритет:** Medium
- **Сложность:** Medium

#### FR-006: Обработка ошибок и edge cases
- **Описание:** Улучшить обработку ошибок
- **Требование:**
  - Проверка доступности SpeechRecognizer
  - Fallback на ручной ввод
  - Обработка неопределенных команд
  - Логгирование ошибок парсинга
- **Приоритет:** High
- **Сложность:** Low

### Нефункциональные требования (Non-Functional Requirements)

#### NFR-001: Производительность
- **Описание:** Время парсинга должно быть < 100ms
- **Текущее:** ~50-80ms (приемлемо)
- **Целевое:** < 50ms
- **Приоритет:** Medium

#### NFR-002: Точность парсинга
- **Описание:** Точность извлечения сущностей
- **Текущее:** ~85-90%
- **Целевое:** > 95%
- **Приоритет:** High

#### NFR-003: Поддержка языков
- **Описание:** Расширить поддержку языков
- **Текущее:** Только русский
- **Целевое:** Русский + Английский (базовый)
- **Приоритет:** Low

## 👤 Персоны

### Персона 1: Опытный пользователь
- **Описание:** Пользуется Floktask ежедневно, хочет быстрого создания задач
- **Цели:**
  - Создавать задачи голосом за минимальное время
  - Минимизировать количество кликов
  - Получать точные результаты парсинга
- **Болевые точки:**
  - Нужно открывать специальный экран для голосового ввода
  - Не всегда правильно распознаются сложные команды
- **Приоритет:** High

### Персона 2: Новый пользователь
- **Описание:** Только начинает использовать Floktask
- **Цели:**
  - Понять, как работает голосовой ввод
  - Получить помощь при ошибках
- **Болевые точки:**
  - Неочевидно, как использовать голосовой ввод
  - Нет обратной связи при ошибках
- **Приоритет:** Medium

### Персона 3: Профессиональный пользователь
- **Описание:** Использует Floktask для работы, нуждается в точности
- **Цели:**
  - Создавать сложные задачи с множеством параметров
  - Интегрировать с другими инструментами
- **Болевые точки:**
  - Ограниченная функциональность парсинга
  - Нет поддержки сложных сценариев
- **Приоритет:** Medium
