# US-003 - Focus Mode

## 📌 Описание

**Как** пользователь Floktask, **я хочу** использовать режим фокуса (Focus Mode), **чтобы** концентрироваться на текущей задаче, минимизировать отвлечения и повышать свою продуктивность.

---

## 🎯 Контекст

### Персона
- **Имя:** Мария, студентка / фрилансер
- **Описание:** Работает над сложными задачами, часто отвлекается
- **Цель:** Повысить концентрацию и продуктивность

### Текущая проблема
В текущей версии Floktask есть базовый функционал для работы с задачами, но отсутствует специализированный режим для концентрации. Пользователи сталкиваются с:
- Постоянными уведомлениями и отвлечениями
- Сложностью сосредоточиться на одной задаче
- Отсутствием инструментов для измерения фокуса
- Нет интеграции с техниками помодоро

### Аналоги у конкурентов
- **Todoist:** Focus View
- **TickTick:** Pomodoro Timer
- **Forest:** Геймифицированный фокус
- **Focus@Will:** Музыка для концентрации
- **Notion:** Full-screen mode

### Взаимодействие

1. **Активация:**
   - Клик по кнопке "Focus Mode" в карточке задачи
   - Горячие клавиши (Ctrl+Shift+F на десктопе)
   - Голосовая команда "Начать фокус"

2. **Работа в режиме:**
   - Автоматическое начало таймера
   - Отображение прогресса
   - Блокировка отвлечений

3. **Управление:**
   - Пауза/возобновление таймера
   - Завершение сессии
   - Выход из режима

4. **После завершения:**
   - Отображение статистики сессии
   - Предложение начать новую сессию
   - Возврат к обычному интерфейсу

## 📋 User Journey

### Сценарий 1: Стандартная сессия Pomodoro
1. Пользователь открывает задачу
2. Кликает "Focus Mode"
3. Начинается 25-минутный таймер
4. Пользователь работает без отвлечений
5. По истечении 25 минут - короткий перерыв (5 минут)
6. После 4 сессий - длинный перерыв (15-30 минут)
7. Сессия завершается, время записывается в статистику

### Сценарий 2: Кастомизированная сессия
1. Пользователь настраивает длительность сессий (например, 45/10)
2. Активирует Focus Mode
3. Работает в течение 45 минут
4. Автоматический перерыв 10 минут
5. Повторяет цикл
6. Просматривает статистику по завершении

### Сценарий 3: Фокус с блокировкой отвлечений
1. Пользователь активирует Focus Mode
2. Выбирает опцию "Блокировать отвлечения"
3. Приложение отключает уведомления
4. (Опционально) Блокирует другие приложения
5. Пользователь работает в полной концентрации
6. По завершении - отключение блокировки

## 🔍 Исследование конкурентов

### Todoist Focus View
**Плюсы:**
- Простой и понятный интерфейс
- Хорошая интеграция с задачами
- Минималистичный дизайн

**Минусы:**
- Нет встроенного таймера
- Ограниченные возможности настройки
- Нет геймификации

### TickTick Pomodoro Timer
**Плюсы:**
- Встроенный таймер Pomodoro
- Хорошая интеграция с задачами
- Статистика сессий

**Минусы:**
- Нет полноэкранного режима
- Ограниченные настройки
- Нет блокировки отвлечений

### Forest App
**Плюсы:**
- Геймифицированный подход
- Визуальная мотивация
- Статистика и достижения

**Минусы:**
- Не интегрирован с таск-менеджером
- Ограниченный функционал
- Платные функции

### Notion Full-screen Mode
**Плюсы:**
- Полноэкранный режим
- Минималистичный дизайн
- Работает с любым контентом

**Минусы:**
- Нет таймера
- Нет отслеживания сессий
- Нет геймификации
