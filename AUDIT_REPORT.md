# 📊 Полный аудит приложения Floktask

## 🎯 Цели проекта
Создать флагманское приложение для управления задачами с функционалом как у Todoist, TickTick и Singularity App.

---

## 🔴 Критические ошибки (P0 - Срочно исправить)

### 1. **Темная тема** ❌
- **Проблема**: Только светлая тема доступна, нет переключателя
- **Воздействие**: Пользователи не могут использовать темный режим
- **Решение**: Добавить переключатель в настройки + сохранить выбор пользователя

### 2. **Голосовой ввод** ❌
- **Проблема**: Вылетает приложение при нажатии на микрофон
- **Причина**: Нет проверки на доступность SpeechRecognizer, отсутствует обработка ошибок
- **Воздействие**: Ключевая фича не работает
- **Решение**: 
  - Добавить проверку `SpeechRecognizer.isRecognitionAvailable()`
  - Обработать все ошибки RecognitionListener
  - Добавить fallback на ручной ввод

### 3. **Закрытие задач/привычек** ❌
- **Проблема**: Нельзя закрыть задачу или привычку
- **Причина**: `onCheckedChange` в TaskCard не связан с ViewModel
- **Воздействие**: Основной функционал не работает
- **Решение**: Подключить обработчики к TaskRepository

### 4. **Eisenhower Matrix - Drag & Drop** ❌
- **Проблема**: Задачи нельзя перемещать между квадрантами
- **Причина**: Логика `onDrop` не вызывает обновление в базе данных
- **Решение**: Исправить ViewModel и добавить анимации

### 5. **Канбан доска** ❌
- **Проблема**: Нет логики как в Todoist
- **Причина**: Отсутствует drag & drop между колонками
- **Решение**: Добавить полноценный DnD с сохранением состояния

## 🟡 Важные улучшения (P1)

### 6. **Привычки - Система серий** ⚠️
- **Проблема**: Нет отслеживания серии выполнений
- **Необходимо**: 
  - Текущая серия (current streak)
  - Лучшая серия (best streak)
  - Процент выполнения
  - Статистика по неделям/месяцам
  - Награды за серии

### 7. **Календарь - Интеграция** ⚠️
- **Проблема**: Нет создания задач из календаря, нет синхронизации
- **Необходимо**:
  - Создание задач по дате
  - Интеграция с Google Calendar
  - Просмотр задач на день/неделю/месяц
  - Синхронизация с системным календарем

### 8. **Проекты и подпроекты** ⚠️
- **Проблема**: Нет возможности создавать подпроекты
- **Необходимо**:
  - Иерархия проектов
  - Перетаскивание задач между проектами
  - Глубина вложенности (2-3 уровня)

### 9. **Иконки и дизайн** ⚠️
- **Проблема**: Today и Habits выглядят одинаково
- **Решение**:
  - Уникальные иконки для каждого раздела
  - Разные цвета акцентов
  - Анимации переходов

### 10. **Haptic Feedback** ⚠️
- **Проблема**: Вибрация не работает
- **Решение**: Подключить HapticManager ко всем действиям
